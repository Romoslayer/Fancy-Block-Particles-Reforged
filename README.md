# Fancy Block Particles (26.2 Port)
This is **Romoslayer's** port of the mod to **Minecraft 26.2**, built on top of Hantonik and TominoCZ's *FBP Renewed*, which itself is a revamp of MorphoxL's original *Fancy Block Particles* mod. See [Credits](#credits) below for the full lineage.

## Downloads

This is a source-available fork, built manually — it isn't published to CurseForge or Modrinth. Grab the source and build it yourself, or check the [Releases](https://github.com/Romoslayer/FancyBlockParticles/releases) page for prebuilt jars (if any are published).

Looking for the officially published, actively-maintained mod on older/newer versions instead? Get it from Hantonik's pages:\
[CurseForge](https://curseforge.com/minecraft/mc-mods/fbp-renewed "Then just click download ;)") · [Modrinth](https://modrinth.com/mod/fbp-renewed "Then just click download ;)")

## Contribution

**Found a bug in this 26.2 port?** Report it [here](https://github.com/Romoslayer/FancyBlockParticles/issues/new "Enter all the necessary information!"), and I'll try to fix it!\
This is just a port to 26.2 — no new features are planned, so feature requests should go to the upstream project instead.
